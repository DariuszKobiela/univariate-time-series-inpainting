Run Experiment:
  • CLI interface
  • Experiment presets (quick/medium/full)
  • Parameter parsing
  • Results summary

Iterative Experiment:
  • Experiment orchestration
  • Data loading & splitting
  • Missingness generation
  • Repair method application
  • Forecasting coordination
  • Metrics calculation
  • Statistical testing
  • Results aggregation

Inpainting:
  • Time series → Image encoding (GAF, MTF, RP, Spectrogram)
  • Image inpainting (UNet, Stable Diffusion 2)
  • Image → Time series decoding
  • Low-level image processing

Visualization:
  • Performance bar charts
  • Statistical test plots
  • ANOVA visualizations
  • Comparison charts
